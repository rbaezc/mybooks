### 💡 ¿Por qué este libro?

Durante años, el patrón MVC horizontal tradicional ha generado monolitos con **Fat Models**, controladores inmanejables y dispersión de la lógica de negocio. Para solucionarlo, la industria empujó el desarrollo hacia complejas Single Page Applications (SPAs) en React/Vue, introduciendo duplicación masiva de código y fricción operativa.

**HexaGenPHP** demuestra cómo construir aplicaciones web ultrarrápidas, robustas y escalables mediante:
1. **Vertical Slice Architecture (VSA):** Organización alrededor de casos de uso y características de negocio.
2. **Arquitectura Hexagonal Pragmática:** Aislamiento del núcleo de negocio mediante puertos y adaptadores.
3. **Live Slices con HTMX:** Reactividad server-driven sin sobrecarga de JavaScript frontend.
4. **Blindaje Criptográfico AES-256-GCM:** Protección zero-trust del estado del cliente.
5. **Eventos de Dominio & CQRS:** Desacoplamiento transaccional y escalabilidad asíncrona.
6. **Multi-Tenancy & CI/CD Enterprise:** Aislamiento estricto de tenants y despliegue dockerizado.

## 🚀 Cómo desplegar en GitHub Pages

1. Haz push a la rama `main` del repositorio `https://github.com/rbaezc/mybooks.git`.
2. En GitHub ve a **Settings** → **Pages**.
3. En **Source**, selecciona **Deploy from a branch**.
4. En Branch, selecciona `main` y la carpeta `/ (root)`.
5. Haz clic en **Save**. ¡El sitio estará disponible inmediatamente en `https://rbaezc.github.io/mybooks/`!
